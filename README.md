# Yangon Taxi Fair 🚕
ရန်ကုန်မြို့တွင်း Taxi ခရီးခကို ခရီးသည်နှင့် Taxi ဆရာ နှစ်ဖက်လုံးအတွက် အကြံပြုတွက်ချက်ပေးရန် V1 PWA။

## V1 နှုန်းထား
- စတင်ခ: 2,500 Ks
- 1 km: 1,200 Ks
- Waiting: 100 Ks / မိနစ်

## Formula
`2,500 + (KM × 1,200) + (Waiting minutes × 100)`

> ဈေးနှုန်းသည် App ၏ အကြံပြု/ပျမ်းမျှတွက်ချက်မှုဖြစ်ပြီး တရားဝင် Taxi fare သတ်မှတ်ချက်ဟု မဆိုလိုပါ။
